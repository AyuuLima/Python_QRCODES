# Sistema de Validação de QR Codes para Eventos

Projeto desenvolvido em Python para gerar e validar QR Codes de convidados em eventos.

## Funcionalidades

- Geração de QR Codes para convidados
- Leitura de QR Codes por imagem
- Validação de convidados
- Registro de entradas
- Controle de uso duplicado de convites
- API simples com Flask
- Testes automatizados
- Integração contínua com GitHub Actions

## Tecnologias utilizadas

- Python
- Flask
- Pandas
- OpenCV
- Pyzbar
- Qrcode
- Pytest

## Como executar

Instalar dependências:

pip install -r requirements.txt

Executar API:

python app.py

Executar testes:

pytest
